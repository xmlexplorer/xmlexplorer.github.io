XML Explorer

XML Explorer is an extremely fast, lightweight XML file viewer. It can handle extremely large XML files. It has been tested on files as big as 300MB. It allows fast viewing and exploration, copying of formatted XML data, evaluation of XPath expressions, and XSD schema validation.

XML Explorer comes in three editions. All three share the same core — a fast tree view, XPath evaluation, and copying of formatted XML — but differ in how they run and what they can handle.

Web-Based

Runs entirely in your browser — nothing to install. Open the site, drag in an XML file (or click Open File), and start exploring. It's the quickest way to take a look at a document and handles everyday files with ease. Because it works within the browser's memory it isn't suited to multi-gigabyte documents, and XSD schema validation is available only in the desktop editions below.

Cross Platform (Linux, MacOS, Windows)

A fast native desktop app with the same modern interface as the web edition. Its Rust + libxml2 engine opens and navigates extremely large XML files smoothly, evaluates XPath, and validates documents against XSD schemas. This is the recommended choice for large files, offline use, or a permanently installed app.

Windows Only (Legacy)

The original .NET (WPF) XML Explorer for Windows. It's stable and battle-tested — proven on files as large as 300 MB — but is no longer actively developed. It also requires .NET Framework 4.0 — released in 2010 and long out of support — which you may need to install separately on a modern system. New users should prefer the cross-platform app above; this download remains for anyone who still depends on it.
