A fast, lightweight viewer for very large XML files

XML Explorer opens XML documents quickly, even huge ones, so you can browse the tree, evaluate XPath expressions, copy formatted XML, and validate against XSD schemas.

Features

Built for big files

The desktop app's Rust and libxml2 engine opens and navigates multi-gigabyte XML files smoothly, loading large lists of child nodes a page at a time.

Fast tree view

Expand and collapse elements, attributes, text and comments in a tree that stays responsive no matter how big the document is.

XPath evaluation

Run XPath expressions against the whole document or a selected node, page through the matches, and jump to any of them in the tree.

XSD schema validation

Validate a document against an XSD schema and see every error and warning with its line and column. Available in the desktop app.

Copy formatted XML

Copy any node and its children to the clipboard as neatly indented XML.

Safe and private

A read-only viewer, so your files are never changed. The web edition reads files in your browser and never uploads them anywhere.

Works everywhere

Any modern browser, plus native apps for Linux, macOS and Windows, with light and dark themes and English, Spanish, Portuguese, Russian and Chinese.

Editions

XML Explorer comes in three editions. All three share the same core — a fast tree view, XPath evaluation, and copying of formatted XML — but differ in how they run and what they can handle.

Web

Runs entirely in your browser — nothing to install. Open the site, drag in an XML file (or click Open File), and start exploring. It's the quickest way to look at a document and handles everyday files with ease. Because it works within the browser's memory it isn't suited to multi-gigabyte documents, and XSD schema validation is available only in the desktop app.

Desktop app (Linux, macOS, Windows)

A fast native app with the same modern interface as the web edition. Its Rust + libxml2 engine opens and navigates extremely large XML files smoothly, evaluates XPath, and validates documents against XSD schemas. The recommended choice for large files, offline use, or a permanently installed app.

Windows only (legacy)

The original .NET (WPF) XML Explorer for Windows. It's stable and battle-tested — proven on files as large as 300 MB — but is no longer actively developed. It requires .NET Framework 4.0 — released in 2010 and long out of support — which you may need to install separately on a modern system. New users should prefer the desktop app; this download remains for anyone who still depends on it.
